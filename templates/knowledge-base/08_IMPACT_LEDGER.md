# 08 — Impact ledger

**Every number, in one place.** If a metric is not on this page, it does not appear in a CV. If
it is on this page, it is used exactly as its tier and attribution allow.

Each row has a stable ID (`M-01`, `M-02`, …) so other files and generated documents cite the ID
rather than re-deriving the number.

## Attribution key

| Code | Meaning | Required phrasing |
|---|---|---|
| `IND` | This person's own scope or deliverable | "Built…", "Reduced…", "Achieved…" |
| `SHARED` | One of a small number of owners | "Co-owned…", "Jointly delivered…" |
| `TEAM` | A project result they contributed to | "Contributed to an initiative that…" |
| `CTX` | Unverified context | Hedge heavily, or omit |
