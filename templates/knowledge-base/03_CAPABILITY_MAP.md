## 8. Honest absences — what is NOT here

**This is the most important section in the file.** Absence here is real absence: no source
evidences it. It is what makes a truthful fit assessment possible, and it is what stops a
generated CV from claiming a capability that collapses in a technical screen.

| Area | Status | Notes for role-fit |
|---|---|---|
| | `Absent` / `Minimal` / `Exposure only` | |

### How to handle an absence in an application

- **Adjacent and learnable:** name the closest real experience and be explicit that the tool
  itself is new.
- **Structurally missing:** if the role is built on it, the honest answer is that the fit is
  weak. That is a useful output, not a failure.
