# Knowledge base templates

**Do not copy all sixteen files.** Sixteen blank templates is how people abandon this on day
one. Start with the core five and grow only when there is material to put in a new file.

## Core — start here

| File | Why it is first |
|---|---|
| `00_START_HERE.md` | The operating contract. Copy it unchanged and edit only the redlines |
| `01_IDENTITY_AND_FACTS.md` | Names, titles, dates, education, contact. Everything references it |
| `08_IMPACT_LEDGER.md` | Every number, one row each, with tier and attribution. The spine |
| `10_CLAIMS_REGISTER.md` | Where contradictions get resolved once, in writing |
| `11_GAPS.md` | What is unknown, recorded as unknown |

With these five you can already generate a defensible CV.

## Recommended — add as material accumulates

| File | Add when |
|---|---|
| `02_POSITIONING.md` | You need to decide a title and a summary |
| `03_CAPABILITY_MAP.md` | Before the first fit assessment — the honest-absences section is what makes one possible |
| `05_PROJECTS.md` | More than two projects worth describing |
| `13_BULLET_LIBRARY.md` | After the first CV, so the second one does not start from scratch |

## Optional — only if they earn their place

| File | Add when |
|---|---|
| `04_TECHNOLOGY_INVENTORY.md` | The stack is wide enough that the capability map cannot carry it |
| `06_DIFFERENTIATOR.md` | There is one unusual capability most peers cannot evidence |
| `07_WAYS_OF_WORKING.md` | Preparing for interviews or writing cover letters |
| `09_RECOGNITION.md` | There are awards or formal recognitions to record |
| `12_ROLE_FIT_GUIDE.md` | After a few fit assessments, to stop re-deriving the same arguments |
| `14_GLOSSARY_AND_TRANSLATION.md` | **Any confidential material at all.** Not optional in that case |
| `99_SOURCE_MAP.md` | Sources have multiplied and provenance is getting hard to track |

## The numbering gap

Numbers are deliberately non-contiguous. They match a stable schema so that files can be added
later without renumbering, and so a reference to `08_IMPACT_LEDGER.md` means the same thing in
every knowledge base built with this framework.
