# 06 — The differentiator

**Optional.** Use this file when the person has one unusual capability that most candidates at
their level cannot evidence — an operating model, a self-built system, an unusual combination
of domains, a practice they invented.

It exists because the strongest thing on a CV is often the hardest to place: too specific for a
skills section, too big for a bullet, and easy to state so vaguely it sounds like nothing.

## How to frame it, and how not to

| Frame it as | Never frame it as |
|---|---|
| Architecture, guardrails and verification | Enthusiasm for a tool |
| A managed system with failure modes | "I'm good at X" |
| Something that compounds and transfers to others | A personal quirk |

## How much to include, by audience

| Audience | Treatment |
|---|---|
| Roles hiring explicitly for this | Top-three bullet. Lead with it |
| Modern teams | One strong bullet |
| Traditional or risk-averse employers | One modest bullet, or omit. Lead with the guardrails, not the velocity |

## Tier honesty

Self-built work is usually Tier B: real, grounded in artifacts, but not externally verifiable.
That is acceptable **when it is stated concretely**, because an interviewer will test it by
asking *how* — and a specific answer at length is more convincing than any adjective.
